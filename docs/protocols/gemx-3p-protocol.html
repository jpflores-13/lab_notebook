Chromium GEM-X Single Cell 3’ v4 Protocol

  • Show All Code
  • Hide All Code
  • View Source

10x Genomics · User Guide CG000731 Rev B

Published

September 3, 2026

NoteOverview

Barcoded Gel Beads, a cell suspension, and Partitioning Oil B are combined on a GEM-X 3’ Chip to generate nanoliter Gel Beads-in-emulsion (GEMs) at limiting dilution, so most GEMs contain either zero or one cell. Reverse transcription inside the GEMs produces barcoded, full-length cDNA from poly-adenylated mRNA. After breaking the emulsion, cDNA is cleaned up, amplified, and a fixed 25% carried forward into 3’ Gene Expression library construction (fragmentation, end repair/A-tailing, adaptor ligation, and sample index PCR), then sequenced.

Four steps: 1 GEM Generation & Barcoding → 2 Post GEM-RT Cleanup & cDNA Amplification → 3 3’ Gene Expression Library Construction → 4 Sequencing.

ImportantBefore starting
  • Equilibrate RT Reagent E, Reducing Agent B, cDNA Primers, Fragmentation Buffer, and Ligation Mix to room temperature before use.
  • Prepare cell suspension in 1X Phosphate-Buffered Saline (PBS); do not add PBS directly to the suspension — PBS is added to the Master Mix instead (Step 1.2c).
  • Prepare fresh 80% ethanol (15 mL per 8 reactions).
  • Thaw Cleanup Buffer for 10 min at 65°C; verify no visible crystals before use.
  • Vortex Dynabeads MyOne SILANE thoroughly (≥30 sec) immediately before adding to any mix — do not centrifuge beforehand.
  • Firmware ≥2.0.0 required for Chromium X/iX; ≥2.2.0 for Chromium Xo.

Step 1: GEM Generation & Barcoding

1.1 Prepare Master Mix

Prepare on ice, pipette mix 15x, centrifuge briefly. Add reagents in the listed order.

Add 28.4 µL Master Mix into each tube of a PCR 8-tube strip on ice (1X per reaction, regardless of how many reactions the batch above covers).

Cell Suspension Volume Calculator

WarningDo not add PBS directly to the cell suspension

Add PBS to the Master Mix instead — see Step 1.2c below.

NoteMath audit — reproduced from the source calculator table

10x Genomics ships this step as a large printed lookup table (Cell Stock Concentration × Targeted Cell Recovery, CG000731 p.34–35) rather than a formula. Back-calculating from >10 entries spanning both halves of that table gives a consistent relationship:

\[V_{cell\ suspension} = \frac{1.45 \times N_{target}}{C_{stock}} \qquad V_{PBS} = 36.6\;\mu L - V_{cell\ suspension}\]

where 36.6 µL is the fixed PBS + cell-suspension allowance (Master Mix 28.4 µL + 36.6 µL = 65 µL total per tube), and 1.45 is the recovery/loading factor implied by the table (≈69% capture efficiency). This reproduces every checked entry in the source table to within its printed rounding (±0.1 µL). If a computed cell suspension volume exceeds 36.6 µL, that combination isn’t achievable — the source table greys these cells out (“exceeds allowable PBS volume”); dilute your stock or lower the target instead.

Code 
cell_susp_vol = 1.45 * target_cells / stock_conc
pbs_vol       = 36.6 - cell_susp_vol

cell_susp_vol > 36.6
  ? md`::: {.callout-warning}
**Not achievable at this concentration.** ${fmt(cell_susp_vol)} µL of cell suspension would be needed, which exceeds the 36.6 µL PBS + cell-suspension allowance. Dilute your stock to at least ${fmt(1.45 * target_cells / 36.6, 0)} cells/µL, or lower the targeted cell recovery.
:::`
  : Inputs.table([
      {Component: "Cell suspension stock", "Volume (µL)": fmt(cell_susp_vol)},

TipLow transfer volume

Cell suspension volumes below ~2 µL are hard to pipette accurately and increase cell-load variability — dilute your stock further if the calculator above returns a very small volume.

1.2 Load GEM-X Chip

Step Action Volume
a If loading <8 reactions/chip, add 50% glycerol to each unused well 60 µL (row 1), 60 µL (row 2), 250 µL (row 3)
b Vortex Gel Bead strip 30 sec in 10x Vortex Adapter; centrifuge ~5 sec; check for bubbles —
c Add PBS volume (above) to Master Mix, then add cell suspension volume (above); total 65 µL/tube Per calculator above
d Load row labeled 1: dispense Master Mix + Cell Suspension into bottom center of each well; wait 30 sec 60 µL/well
e Load row labeled 2: aspirate Gel Beads (puncture foil first), dispense; wait 30 sec 60 µL/well
f Load row labeled 3: dispense Partitioning Oil B from a reservoir, 2× 125 µL aliquots 250 µL/well
g Close chip holder (gasket attached); do not press on top of gasket; keep horizontal —
WarningPartitioning Oil B is mandatory

Failure to add Partitioning Oil B to row 3 will prevent GEM generation and can damage the instrument. Run the chip on the Chromium X series instrument immediately after loading.

1.3 Run the Chromium X Series Instrument

  1. Eject tray; place assembled chip with gasket, keeping it horizontal; retract tray.
  2. Confirm the GEM-X 3P program on screen; press play.
  3. Run takes ~6 min; instrument chimes at completion — proceed immediately.

1.4 Transfer GEMs

  1. Place a tube strip on ice.
  2. Eject chip; discard gasket; fold lid back to expose wells at 45°.
  3. Check rows 1–2 for abnormally high remaining volume (possible clog indicator).
  4. Slowly aspirate 100 µL GEMs from the lowest point of each recovery well (top NO FILL row) without sealing tips against the well bottom.
  5. Dispense into the tube strip on ice over ~20 sec, tips against the sidewalls.
  6. Start GEM incubation within 5 min. Route GEMs from separate chips to separate thermal cyclers if running back-to-back.

1.5 GEM-RT Incubation

Use a thermal cycler holding ≥100 µL (125 µL preferred, e.g. Bio-Rad C1000 Touch — use the highest available reaction volume setting on other instruments).

Store at 4°C up to 72 h, or −20°C up to 1 week, or proceed directly.

Step 2: Post GEM-RT Cleanup & cDNA Amplification

2.1 Post GEM-RT Cleanup — Dynabeads

  1. Add 125 µL Recovery Agent to each sample at room temperature. Do not pipette mix or vortex the biphasic mixture. Wait 2 min.
  2. Slowly remove and discard 125 µL Recovery Agent/Partitioning Oil (pink, bottom layer) — do not aspirate the aqueous phase.
  3. Prepare the Dynabeads Cleanup Mix (vortex SILANE beads ≥30 sec immediately before use; do not centrifuge):

2.4 Post cDNA Amplification QC & Quantification

Run 1 µL (undiluted for low-RNA-content cells <1 pg total RNA/cell; 1:5–1:10 diluted for high-RNA-content cells) on a Bioanalyzer High Sensitivity chip (or TapeStation/LabChip). Select the ~200–9,000 bp region and read the reported concentration (pg/µL).

NoteYield calculator (reproduces the source worked example)

\[Total\ Yield\ (ng) = \frac{Conc.\ (pg/\mu L) \times Elution\ Vol.\ (\mu L) \times Dilution\ Factor}{1000}\] Only 25% of total cDNA yield is carried forward into Gene Expression library construction (Step 3.1d).

Code 
viewof qc_conc      = Inputs.number({label: "Reported concentration (pg/µL)", value: 2005.93, min: 0, step: 0.01})
viewof qc_elution_uL = Inputs.number({label: "Elution volume (µL)", value: 40, min: 0, step: 0.5})
viewof qc_dilution  = Inputs.number({label: "Dilution factor", value: 10, min: 1, step: 1})
Code 
cdna_total_yield_ng = (qc_conc * qc_elution_uL * qc_dilution) / 1000
cdna_carry_forward_ng = cdna_total_yield_ng * 0.25

md`**Total cDNA yield: ${fmt(cdna_total_yield_ng, 2)} ng · Carry forward (25%) into GEX library construction: ${fmt(cdna_carry_forward_ng, 2)} ng** — see Step 3.5 for the matching Sample Index PCR cycle count.`

Step 3: 3’ Gene Expression Library Construction

NoteFixed-proportion input

Only 10 µL (25%) of the 40 µL total cDNA from Step 2.3m goes into fragmentation — regardless of total yield. The remaining 30 µL (75%) can be stored at 4°C (≤72 h) or −20°C (≤4 weeks) for additional libraries.

TipPeaks below 200 bp on QC?

Repeat this step: bring the library to 100 µL with nuclease-free water before repeating 3.6a. Expect ~40% material loss on a repeat. Alternatively, pool libraries destined to be sequenced together first, then run the pool through 3.6.

3.7 Post Library Construction QC & Quantification

Run 1 µL at 1:10 dilution on Bioanalyzer High Sensitivity (or TapeStation/LabChip); select the 200–2,000 bp region for average library size (used as insert size for quantification). Use a qPCR-based method (e.g. KAPA Library Quantification Kit) for the most accurate loading concentration ahead of sequencing.

WarningIndex hopping mitigation

Store each library individually (4°C ≤72 h, or −20°C long-term) — do not pool during storage. Pool only immediately before sequencing; an extra 1.0X SPRI cleanup on the pooled libraries can remove residual free adaptors. Never pool two libraries sharing the same sample index in one lane — this breaks demultiplexing.

Compatible sequencers: MiSeq, NextSeq 500/550/2000, HiSeq 2500 (Rapid Run), HiSeq 3000/4000, NovaSeq 6000. Data is analyzed with Cell Ranger (BCL/FASTQ → BAM, MEX, CSV, HDF5, web summary, .cloupe) and visualized in Loupe Browser.

```{ojs}
mm_scale    = (x, n) => x * n * 1.10   // standard master mixes: N reactions + 10% excess
plain_scale = (x, n) => x * n          // Elution Solution I: exact N×, no excess
fmt         = (x, d = 1) => x.toFixed(d)

md`**${n_reactions} reaction(s) · targeting ${target_cells} cells · ${stock_conc} cells/µL stock**`
```

::: {.callout-tip collapse="true"}
## Running more than 8 reactions
Only one GEM-X 3' Chip is used per run, with a maximum of 8 reaction wells. For more than 8 samples, run additional chips separately and repeat this protocol per chip (up to 8 reactions per chip's worth of master mix).
:::

## Step 1: GEM Generation & Barcoding

### 1.1 Prepare Master Mix

Prepare on ice, pipette mix 15x, centrifuge briefly. Add reagents in the listed order.

```{ojs}
//| echo: false
Inputs.table([
  {Component: "RT Reagent E (PN-2001106)",           "1X (µL)": 16.3, [`${n_reactions}X + 10% (µL)`]: fmt(mm_scale(16.3, n_reactions))},
  {Component: "Template Switch Oligo B (PN-2001027)", "1X (µL)": 3.1,  [`${n_reactions}X + 10% (µL)`]: fmt(mm_scale(3.1,  n_reactions))},
  {Component: "Reducing Agent B (PN-2000087)",         "1X (µL)": 2.0,  [`${n_reactions}X + 10% (µL)`]: fmt(mm_scale(2.0,  n_reactions))},
  {Component: "RT Enzyme E (PN-2001105/2001146)",      "1X (µL)": 7.0,  [`${n_reactions}X + 10% (µL)`]: fmt(mm_scale(7.0,  n_reactions))},
  {Component: "Total",                                 "1X (µL)": 28.4, [`${n_reactions}X + 10% (µL)`]: fmt(mm_scale(28.4, n_reactions))}
], {layout: "auto"})
```

Add 28.4 µL Master Mix into each tube of a PCR 8-tube strip on ice (1X per reaction, regardless of how many reactions the batch above covers).

### Cell Suspension Volume Calculator

::: {.callout-warning}
## Do not add PBS directly to the cell suspension
Add PBS to the Master Mix instead — see Step 1.2c below.
:::

::: {.callout-note collapse="true"}
## Math audit — reproduced from the source calculator table
10x Genomics ships this step as a large printed lookup table (Cell Stock Concentration × Targeted Cell Recovery, CG000731 p.34–35) rather than a formula. Back-calculating from >10 entries spanning both halves of that table gives a consistent relationship:

$$V_{cell\ suspension} = \frac{1.45 \times N_{target}}{C_{stock}} \qquad V_{PBS} = 36.6\;\mu L - V_{cell\ suspension}$$

where 36.6 µL is the fixed PBS + cell-suspension allowance (Master Mix 28.4 µL + 36.6 µL = 65 µL total per tube), and 1.45 is the recovery/loading factor implied by the table (≈69% capture efficiency). This reproduces every checked entry in the source table to within its printed rounding (±0.1 µL). If a computed cell suspension volume exceeds 36.6 µL, that combination isn't achievable — the source table greys these cells out ("exceeds allowable PBS volume"); dilute your stock or lower the target instead.

<!-- TODO: this constant is empirically derived from the printed table, not stated explicitly as a formula in the source document. Sanity-check against CG000731 p.34-35 for your specific concentration/target if it matters for a critical run. -->
:::

```{ojs}
//| echo: false
cell_susp_vol = 1.45 * target_cells / stock_conc
pbs_vol       = 36.6 - cell_susp_vol

cell_susp_vol > 36.6
  ? md`::: {.callout-warning}
**Not achievable at this concentration.** ${fmt(cell_susp_vol)} µL of cell suspension would be needed, which exceeds the 36.6 µL PBS + cell-suspension allowance. Dilute your stock to at least ${fmt(1.45 * target_cells / 36.6, 0)} cells/µL, or lower the targeted cell recovery.
:::`
  : Inputs.table([
      {Component: "Cell suspension stock", "Volume (µL)": fmt(cell_susp_vol)},
      {Component: "1X Phosphate-Buffered Saline (PBS)", "Volume (µL)": fmt(pbs_vol)},
      {Component: "Total (added to Master Mix)", "Volume (µL)": fmt(cell_susp_vol + pbs_vol)}
    ], {layout: "auto"})
```

::: {.callout-tip collapse="true"}
## Low transfer volume
Cell suspension volumes below ~2 µL are hard to pipette accurately and increase cell-load variability — dilute your stock further if the calculator above returns a very small volume.
:::

### 1.2 Load GEM-X Chip

| Step | Action | Volume |
|------|--------|--------|
| a | If loading <8 reactions/chip, add 50% glycerol to each **unused** well | 60 µL (row 1), 60 µL (row 2), 250 µL (row 3) |
| b | Vortex Gel Bead strip 30 sec in 10x Vortex Adapter; centrifuge ~5 sec; check for bubbles | — |
| c | Add PBS volume (above) to Master Mix, then add cell suspension volume (above); total 65 µL/tube | Per calculator above |
| d | Load row labeled **1**: dispense Master Mix + Cell Suspension into bottom center of each well; wait 30 sec | 60 µL/well |
| e | Load row labeled **2**: aspirate Gel Beads (puncture foil first), dispense; wait 30 sec | 60 µL/well |
| f | Load row labeled **3**: dispense Partitioning Oil B from a reservoir, 2× 125 µL aliquots | 250 µL/well |
| g | Close chip holder (gasket attached); do not press on top of gasket; keep horizontal | — |

::: {.callout-warning}
## Partitioning Oil B is mandatory
Failure to add Partitioning Oil B to row 3 will prevent GEM generation and can damage the instrument. Run the chip on the Chromium X series instrument immediately after loading.
:::

### 1.3 Run the Chromium X Series Instrument

a. Eject tray; place assembled chip with gasket, keeping it horizontal; retract tray.
b. Confirm the GEM-X 3P program on screen; press play.
c. Run takes ~6 min; instrument chimes at completion — proceed immediately.

### 1.4 Transfer GEMs

a. Place a tube strip on ice.
b. Eject chip; discard gasket; fold lid back to expose wells at 45°.
c. Check rows 1–2 for abnormally high remaining volume (possible clog indicator).
d. Slowly aspirate **100 µL** GEMs from the lowest point of each recovery well (top NO FILL row) without sealing tips against the well bottom.
e. Dispense into the tube strip on ice over ~20 sec, tips against the sidewalls.
f. Start GEM incubation within 5 min. Route GEMs from separate chips to separate thermal cyclers if running back-to-back.

### 1.5 GEM-RT Incubation

Use a thermal cycler holding ≥100 µL (125 µL preferred, e.g. Bio-Rad C1000 Touch — use the highest available reaction volume setting on other instruments).

| Lid | Reaction volume | Run time |
|-----|-----------------|----------|
| 48°C | 125 µL | ~55 min |

| Step | Temperature | Time |
|------|-------------|------|
| 1 | 48°C | 00:45:00 |
| 2 | 85°C | 00:05:00 |
| 3 | 4°C | Hold |

Store at 4°C up to 72 h, or −20°C up to 1 week, or proceed directly.

## Step 2: Post GEM-RT Cleanup & cDNA Amplification

### 2.1 Post GEM-RT Cleanup — Dynabeads

a. Add **125 µL Recovery Agent** to each sample at room temperature. Do **not** pipette mix or vortex the biphasic mixture. Wait 2 min.
b. Slowly remove and discard **125 µL** Recovery Agent/Partitioning Oil (pink, bottom layer) — do not aspirate the aqueous phase.
c. Prepare the Dynabeads Cleanup Mix (vortex SILANE beads ≥30 sec immediately before use; do not centrifuge):

### 2.4 Post cDNA Amplification QC & Quantification

Run 1 µL (undiluted for low-RNA-content cells <1 pg total RNA/cell; 1:5–1:10 diluted for high-RNA-content cells) on a Bioanalyzer High Sensitivity chip (or TapeStation/LabChip). Select the ~200–9,000 bp region and read the reported concentration (pg/µL).

::: {.callout-note collapse="true"}
## Yield calculator (reproduces the source worked example)
$$Total\ Yield\ (ng) = \frac{Conc.\ (pg/\mu L) \times Elution\ Vol.\ (\mu L) \times Dilution\ Factor}{1000}$$
Only **25%** of total cDNA yield is carried forward into Gene Expression library construction (Step 3.1d).
:::

```{ojs}
//| echo: false
viewof qc_conc      = Inputs.number({label: "Reported concentration (pg/µL)", value: 2005.93, min: 0, step: 0.01})
viewof qc_elution_uL = Inputs.number({label: "Elution volume (µL)", value: 40, min: 0, step: 0.5})
viewof qc_dilution  = Inputs.number({label: "Dilution factor", value: 10, min: 1, step: 1})
```

```{ojs}
//| echo: false
cdna_total_yield_ng = (qc_conc * qc_elution_uL * qc_dilution) / 1000
cdna_carry_forward_ng = cdna_total_yield_ng * 0.25

md`**Total cDNA yield: ${fmt(cdna_total_yield_ng, 2)} ng · Carry forward (25%) into GEX library construction: ${fmt(cdna_carry_forward_ng, 2)} ng** — see Step 3.5 for the matching Sample Index PCR cycle count.`
```

::: {.callout-note}
## Fixed-proportion input
Only **10 µL (25%)** of the 40 µL total cDNA from Step 2.3m goes into fragmentation — regardless of total yield. The remaining 30 µL (75%) can be stored at 4°C (≤72 h) or −20°C (≤4 weeks) for additional libraries.

## Peaks below 200 bp on QC?
Repeat this step: bring the library to 100 µL with nuclease-free water before repeating 3.6a. Expect ~40% material loss on a repeat. Alternatively, pool libraries destined to be sequenced together first, then run the pool through 3.6.

Use a qPCR-based method (e.g. KAPA Library Quantification Kit) for the most accurate loading concentration ahead of sequencing.

::: {.callout-warning}
## Index hopping mitigation
Store each library individually (4°C ≤72 h, or −20°C long-term) — **do not** pool during storage. Pool only immediately before sequencing; an extra 1.0X SPRI cleanup on the pooled libraries can remove residual free adaptors. Never pool two libraries sharing the same sample index in one lane — this breaks demultiplexing.
:::
