Agilent High Sensitivity D1000 ScreenTape Assay · 2200 TapeStation

Published

September 9, 2026

NoteOverview

The High Sensitivity D1000 ScreenTape assay determines the average fragment size and concentration of DNA samples on the Agilent 2200 TapeStation. Samples are mixed with HS D1000 Sample Buffer, vortexed, spun down, and loaded directly onto the instrument alongside an (optional) ladder — no gel to pour, no post-run imaging steps.

ImportantBefore starting
  • Launch the 2200 TapeStation Controller Software and load the High Sensitivity D1000 ScreenTape device + loading tips into the instrument.
  • Allow HS D1000 Reagents (Ladder and Sample Buffer) to equilibrate at room temperature for 30 min before use.
  • Vortex all reagents before use.
  • Have an IKA vortexer with 96-well adaptor ready (2000 rpm).

Configure run

Code 
viewof n_samples    = Inputs.number({label: "Number of samples", value: 8, min: 1, max: 16, step: 1})
viewof include_ladder = Inputs.toggle({label: "Include ladder lane", value: true})
viewof excess_pct   = Inputs.number({label: "Extra overage on Sample Buffer master mix (%)", value: 10, min: 0, max: 30, step: 5})
Code 
scale = 1 + excess_pct / 100
fmt   = (x, d = 2) => x.toFixed(d)

md`**${n_samples} sample(s)${include_ladder ? " + 1 ladder lane" : ""} · ${excess_pct}% overage on Sample Buffer**`
TipWhy a Sample Buffer “master mix” at all?

The source protocol describes mixing Sample Buffer + DNA one tube at a time (3 µL + 1 µL). Since Sample Buffer is identical across every sample, it’s more efficient to pre-aliquot a single Sample Buffer master mix (scaled to your sample count + overage) rather than pipetting 3 µL from the stock tube per sample. The overage percentage is a bench-practice addition to cover pipetting dead volume — not a value stated in the source document.

Sample & ladder preparation

NoteMath audit — how the master mix totals are calculated

Each sample tube needs 3 µL Sample Buffer + 1 µL DNA (4 µL total load volume). The ladder tube (if run) needs 2 µL Sample Buffer + 2 µL Ladder. Total Sample Buffer to pre-aliquot:

\[V_{SampleBuffer} = \big(3\;\mu L \times N_{samples} + 2\;\mu L \times \mathbb{1}_{ladder}\big) \times (1 + overage)\]

DNA input volume is fixed at 1 µL/sample regardless of concentration — this assay does not back-calculate a target mass, unlike, e.g., the cDNA synthesis RNA input step.

Code 
sample_buffer_total = (3 * n_samples + (include_ladder ? 2 : 0)) * scale

Inputs.table([
  {Component: "HS D1000 Sample Buffer", "Per reaction (µL)": "3 (samples) / 2 (ladder)", "Total to aliquot (µL)": fmt(sample_buffer_total)},
  {Component: "HS D1000 Ladder",        "Per reaction (µL)": include_ladder ? "2 (ladder tube only)" : "not used", "Total to aliquot (µL)": include_ladder ? "2" : "—"}
], {layout: "auto"})
Code 
Inputs.table([
  {Tube: "Each sample", "Sample Buffer (µL)": 3, "Input (µL)": "1 µL DNA sample", "Total (µL)": 4},
  {Tube: "Ladder (optional)", "Sample Buffer (µL)": 2, "Input (µL)": "2 µL HS D1000 Ladder", "Total (µL)": 4}
], {layout: "auto"})
