EpiCypher CUTANA CUT&RUN, no crosslinking, with full library prep

Published

September 9, 2026

NoteOverview

CUT&RUN in untreated HCT116 (and K562) cells for H3K27ac and HA, no crosslinking. Cells are bound to Concanavalin A (ConA)-coated beads, permeabilized, and incubated with primary antibody overnight; pAG-MNase is then bound and activated with calcium to cleave and release antibody-targeted chromatin. Released DNA is purified with the CUTANA™ DNA Purification Kit, then carried through full CUTANA™ CUT&RUN library prep (End Repair, Adaptor Ligation & U-Excision, DNA Cleanup, Indexing PCR, PCR Cleanup) for sequencing. This is a separate, more detailed protocol from this notebook’s existing CUT&RUN protocol (Skene et al. 2018) — use whichever matches your workflow (EpiCypher CUTANA kit-based here vs. the Phanstiel-lab bench protocol there).

Source document header: “MOPS: Cut and Run for H3K27ac and HA with no crosslinking” — written by AP, modified by HK, YQ, ZD, DCA. Adapted from EpiCypher’s CUTANA CUT&RUN protocol, its crosslinking modification, and the CUTANA CUT&RUN Library Prep Kit manual. Troubleshooting guide: bionordika.no.

ImportantBefore starting
  • Set centrifuge to 4°C.
  • Prepare Wash Buffer fresh on Day 1 and Day 2 (filter after prep); keep at room temperature (RT).
  • Prepare Digitonin Buffer fresh each day from that day’s Wash Buffer; keep at 4°C; discard leftover Wash Buffer after making it.
  • Prepare Antibody Buffer fresh for Day 1; keep on ice.
  • Prepare 8-strip tubes and 1.5 mL tubes for QC checks ahead of time.
  • Record your i5/i7 index assignment before opening any adapter tubes — index swaps are invisible until sequencing data arrives.
  • Maintain 4°C during adapter ligation setup — this is the primary source of adapter dimers in library prep.
  • Make fresh 85% ethanol (EtOH) on the day of each cleanup — do not store it.

Library prep

NoteInput

5 ng input DNA is recommended for most CUT&RUN targets; robust, reliable sequencing data have been obtained down to 0.5 ng. Use as much DNA as possible when yield is limiting.

WarningTemperature & reagent handling

Maintain 4°C during library prep to avoid adapter dimer formation. End Prep Buffer and Ligation Mix can precipitate at −20°C — if observed, bring to RT, gently vortex until dissolved, and return to ice. Mix reactions with three 4-second gentle vortex pulses (setting 7/10), flick/invert 8-strip tubes, and quick spin — this mixes viscous reagents without losing enzyme activity.

Notei5/i7 set selection rule (from source)
  1. Determine the number of CUT&RUN libraries to multiplex.
  2. Select i7 Set(s) — at least one complete i7 Set must be included per sequencing run.
  3. Work through all i5 primer combinations for a given i7 Set before moving to another i7 Set. Select i5 primer(s) to pair with the chosen i7 Set(s) — at least one complete i5 Set must be included per run.
  4. Assign i5/i7 pairs to reactions in a way that simplifies multichannel pipetting.
  5. Add 1 µL assigned i7 primer, then 1 µL assigned i5 primer, to each reaction — change tips between additions to prevent cross-contamination, and discard/replace the i7 tube cap after each use.

Example from source: “For Run 1, we select the i7.1 & i7.2 Set.”

## Overview
CUT&RUN in untreated HCT116 (and K562) cells for H3K27ac and HA, no crosslinking. Cells are bound to Concanavalin A (ConA)-coated beads, permeabilized, and incubated with primary antibody overnight; pAG-MNase is then bound and activated with calcium to cleave and release antibody-targeted chromatin. Released DNA is purified with the CUTANA™ DNA Purification Kit, then carried through full CUTANA™ CUT&RUN library prep (End Repair, Adaptor Ligation & U-Excision, DNA Cleanup, Indexing PCR, PCR Cleanup) for sequencing. ## Before starting
- Set centrifuge to 4°C.

Every master mix in this protocol is scaled with its **own** stated pipetting-error excess, not one global figure — the source document varies this per step:

$$V_{total} = V_{per\_reaction} \times N_{samples} \times (1 + excess)$$

## i5/i7 set selection rule (from source)
1. Determine the number of CUT&RUN libraries to multiplex.
2. Select i7 Set(s) — at least one complete i7 Set must be included per sequencing run.
3. Work through **all** i5 primer combinations for a given i7 Set before moving to another i7 Set. Select i5 primer(s) to pair with the chosen i7 Set(s) — at least one complete i5 Set must be included per run.
4. Assign i5/i7 pairs to reactions in a way that simplifies multichannel pipetting.
5. Add 1 µL assigned i7 primer, then 1 µL assigned i5 primer, to each reaction — change tips between additions to prevent cross-contamination, and discard/replace the i7 tube cap after each use.

Example from source: *"For Run 1, we select the i7.1 & i7.2 Set."*

## Sequencing guidance (from source)
Paired-end sequencing (2 × 50 bp) is recommended to identify sites of MNase cleavage and enable target footprinting (e.g. for transcription factors). 3–8 million reads provides adequate coverage for most targets. This protocol generates nucleosome-resolution data (~170 bp) for transcription factors; prepping subnucleosomal fragments (<120 bp) requires protocol adjustments not detailed in this source (see EpiCypher FAQs).
:::
